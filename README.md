# ハンドメイド作品カタログ

作品をURLで紹介できるカタログサイトです。Next.js + TypeScript で作っています。データベースは使いません。

| 画面 | URL |
| --- | --- |
| 作品一覧 | `/` |
| カテゴリ絞り込み | `/category/wood/`(木工)、`/category/ceramic/`(陶芸)、`/category/accessory/`(アクセサリー) |
| 作品詳細 | `/works/w001/` など |

## 手元で確認する

このフォルダでターミナル(PowerShell)を開き、次を実行します。

```powershell
npm run dev
```

ブラウザで <http://localhost:3000/> を開きます。止めるときは、ターミナルで `Ctrl + C` を押します。

## 作品を追加・変更する

編集するのは `src/data/works.ts` だけです。

1. 写真を `public/images/` フォルダに入れます。ファイル名は半角英数字にしてください。
2. `WORKS` の中に、次のかたまりを追加します。

```ts
{
  id: "w010",                     // 他と重ならない半角英数字。作品ページのURLになる
  name: "作品名",
  category: "木工",               // 木工 / 陶芸 / アクセサリー のどれか
  photoUrl: "/images/photo.jpg",  // 外部の写真なら "https://..." と書く
  description: "説明文。\n で改行できます。",
},
```

3. 保存すると、`npm run dev` で開いている画面に反映されます。

サイト名と紹介文は、同じファイルの先頭にある `SITE` で変更できます。

### うまくいかないとき

- 写真が「画像なし」になる場合は、`photoUrl` とファイル名が一致しているか確認してください。公開先では大文字と小文字も区別されるため、`Photo.JPG` と `photo.jpg` は別のファイルとして扱われます。
- 写真は一覧と詳細で正方形に切り抜かれます。正方形に近い写真がきれいに見えます。
- 外部の写真を使うときは、使ってよい写真か確認してください。リンク先で写真が消えると「画像なし」になります。
- `category` を3種類以外にすると、次の公開用データ作成(`npm run build`)でエラーになります。同じ `id` を2回使った場合も同様です。

## 公開する

公開すると、URLを知っている人は誰でも見られます。仮データ(`src/data/works.ts` と `public/images/` の仮の写真)を本物に差し替えてから公開してください。

1. このフォルダで公開用データを作ります。`out` フォルダができます。

   ```powershell
   npm run build
   ```

2. <https://app.netlify.com/drop> を開きます。
3. `out` フォルダをページにドラッグ&ドロップします。`my-catalog-next` フォルダ全体ではなく、`out` フォルダだけを入れてください。
4. 表示されたURLで確認します。残しておくには、案内に従って無料アカウントを作成します。

作品を変更したときは、もう一度 `npm run build` を実行し、Netlify の管理画面から `out` フォルダをアップロードし直します。
